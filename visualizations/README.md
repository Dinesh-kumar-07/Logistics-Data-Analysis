# Visualizations

This folder contains visualization outputs generated during the logistics data analysis.

The visualizations include:

- Monthly On-Time Delivery Rate
- Delivery Delay Rate by State
- Freight Cost vs Delivery Lead Time
- Delivery Lead-Time Distribution
- Freight Cost Distribution
- Correlation Heatmap
- Actual vs Predicted Delivery Time
- Feature Importance
- Confusion Matrix
- Regional Clustering
- Route Optimization
